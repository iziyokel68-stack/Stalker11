# STALKER — приложение мастера

Единая программа на ноутбуке мастера: регистрация, список участников,
программатор устройств, общие оповещения, доска заданий, статистика.

Канон: `docs/PROGRESSION.txt` §10, `ROADMAP.md` Фаза 4.

## Запуск

```bash
cd stalker_app
pip install pyserial pygame
python main.py
```

Базы событий: `stalker_app/events/stalker_event_<id>.db` (можно копировать на USB).

## Модули

| Меню | Что делает |
|------|------------|
| Событие | Игровой день, счётчики, экспорт/импорт `.db` |
| Участники | Список, группы, `CONFIG:REGISTER` / `CONFIG:ADMIT` на ПДА |
| Программатор | `programmat_pc/programmer.py` (чипы, аномалии, убежища, ПДА, терминалы) |
| Оповещения | Журнал + USB `CONFIG:BROADCAST` / выброс / радио |
| Задания | Каталог квестов события (доска) |
| Статистика | Снимок прогресса, CSV, опционально `CONFIG_READ` |
| Команды | Допуск / воскрешение / UID |
| Карта | Место под схему полигона (UWB якоря — позже) |

Программатор открывается отдельным окном и занимает COM, пока не закрыт.
