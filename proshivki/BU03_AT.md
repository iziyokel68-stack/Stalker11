# Прошивка STM на BU03 (AT) — самостоятельно

ESP32 **не** прошивает модуль UWB. На BU03 свой контроллер (обычно **STM32F103**). Arduino IDE его не видит. В репозитории **нет** `.bin` / `.hex`: у разных партий и клонов — **разные** образы AT.

Боевые скетчи ПДА и поля говорят с модулем только UART **115200**, строки с `\r\n`. Если на `AT` нет `OK` — сначала эта инструкция, не пины ESP.

Эталон команд после удачной заливки: `MASTER_SPECIFICATION.md` §3 (BU03). Заливка ESP: `FLASHING.md`.

---

## 1. Что вы прошиваете

| Слой | Чем | Файл |
| --- | --- | --- |
| ESP32-S3 (ПДА / поле) | Arduino IDE | `.ino` из `proshivki/` |
| STM32 на BU03 | STM32CubeProgrammer / FlyMcu / ST-Link | `.bin` / `.hex` **вашего** вендора |

Нужна прошивка **с AT-командами**, не «голый» пример TWR из Keil SDK. Если залить SDK-демо без AT, ESP будет слать `AT` в пустоту.

Официальный SDK Ai-Thinker (если собираете сами в Keil): [STM32F103-BU0x_SDK](https://github.com/Ai-Thinker-Open/STM32F103-BU0x_SDK). Готовый AT-образ берите у поставщика модуля / с диска к Kit — **не из этого репозитория**.

---

## 2. Как войти в загрузчик STM32

На **BU03-Kit** (плата с кнопками BOOT и RESET):

1. Зажать **BOOT** (BOOT0 = 1).
2. Нажать и отпустить **RESET**.
3. Отпустить **BOOT**.
4. STM в системном загрузчике: USB DFU и/или UART ISP.

На голом модуле без кнопок: вывод BOOT0 на 3V3, импульс NRST, потом BOOT0 на GND для обычного старта.

Не оставляйте BOOT0 поднятым после прошивки — модуль снова уйдёт в загрузчик и не ответит на `AT`.

---

## 3. Чем лить образ (любой удобный путь)

### A. STM32CubeProgrammer + USB DFU

1. [STM32CubeProgrammer](https://www.st.com/en/development-tools/stm32cubeprog.html) (Windows / Linux / macOS).
2. Войти в загрузчик (§2). Кабель в USB Kit.
3. В программе: интерфейс **USB**, Refresh, Connect.
4. Open file → ваш `.bin` / `.hex` / `.elf`.
5. Address для `.bin` обычно `0x08000000` (Flash STM32F1).
6. Start Programming, галка **Run after programming**.
7. BOOT0 = 0, Reset. UART 115200 — должен ответить на `AT`.

### B. UART ISP (USB-UART к TX/RX Kit)

Тот же загрузчик. В CubeProgrammer интерфейс **UART**, 115200, even parity для ROM bootloader F1 (если не коннектится — попробуйте 8E1). Либо **FlyMcu**: порт, файл `.hex`, «начать программирование» при зажатом BOOT + RESET.

### C. ST-Link / J-Link (SWD)

Пин-хедер Kit: **SWDIO**, **SWCLK**, GND, 3V3. CubeProgrammer → **ST-LINK**, Connect, прошить файл. Не кормите модуль 5V и ST-Link 3V3 одновременно без общей земли.

## 4. После заливки: какой это AT

Разные прошивки — разный набор команд. Сразу снимите отпечаток, **до** калибровки и до игры.

Подключите USB-UART к UART модуля (**не** к ESP), 115200, перевод строки **CRLF** (`\r\n`):

```
AT
AT+VERSION
AT+HELP
AT+GETCFG
```

Запишите ответ. По нему видно, Ai-Thinker AT это или клон.

### Диалект, который ждут боевые `.ino`

| Команда | Зачем |
| --- | --- |
| `AT` → `OK` | жив ли UART |
| `AT+SETUWBMODE=0` | TWR (если команды нет — ESP игнорирует ошибку) |
| `AT+SETCFG=<id>,<role>,<ch>,<rate>` | id 0–10, **role 0=tag / 1=anchor**, канал и скорость |
| `AT+SAVE` | запомнить в STM |
| `AT+DISTANCE` | на **anchor**: строка с `distance:` и `OK` |
| `AT+GETCFG` | проверка ID/роли |
| `AT+SETDEV=<a>,<b>` | калибровка метров **на полигоне** |
| `AT+RESTART` | мягкая перезагрузка STM |

Полигон STALKER: **CH:1**, **Rate:1**, TWR. Роли:

- аномалия = **anchor** (role=1), свой `uwb_id`;
- ПДА у аномалии = **tag** (role=0), слот выдаёт поле;
- убежище = **tag** с фиксированным id; ПДА у входа = **anchor id=0**.

ESP на ПДА: Serial1 **G1/G2**, питание ключ **G42**. Поле — те же пины.

### Если команды другие

Клоны часто дают `AT+RANGE` вместо `AT+DISTANCE`, другой `SETCFG`, или JSON. Тогда:

1. Либо найдите/соберите AT-прошивку **с таблицей выше** (тот же вендор, что у остальных точек).
2. Либо не ждите зон в боевых скетчах: без `OK` на `AT` поле уйдёт в ESP-NOW **broadcast** (как стенд без UWB).

Не смешивайте на одном полигоне два диалекта: слоты и метры разъедутся.

---

## 5. Калибровка метров (`AT+SETDEV`)

Это не прошивка ESP и не первая заливка STM. На каждой точке (аномалия / убежище) по методике Excel/доки Ai-Thinker подберите `a,b`, запишите `AT+SETDEV`, затем `AT+SAVE`. Пока не откалибровано, `AT+DISTANCE` врёт на метры — радиус в программаторe будет «не тот».

---

## 6. Типичные сбои

| Симптом | Что проверить |
| --- | --- |
| ESP: `[BU03] NO LINK` | TX/RX не перепутаны с G1/G2, G42 = 1, 3V3, BOOT0 не в загрузчике |
| `AT` молчит после «успешной» заливки | залит не AT-образ / BOOT0 всё ещё 1 / другой UART (TX1/RX1 vs USB-UART Kit) |
| `SETCFG` → `ERR` | чужой диалект AT или id вне 0–10 |
| `DISTANCE` → `ERR` / нет `distance:` | опрос не на anchor, или команда называется иначе (`RANGE`) |
| Две аномалии, один ПДА, странный урон | у якорей **разные** `uwb_id`; канал/rate одинаковые |

Проверка модуля без игры: `test_firmware/Test_PDA_Hardware/` (плата ПДА) или USB-UART + ручной `AT`.
