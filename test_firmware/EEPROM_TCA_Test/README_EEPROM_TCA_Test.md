# EEPROM + TCA9548A — тестовая прошивка

> Документация проекта: `MASTER_SPECIFICATION.md` §3 (TCA/EEPROM), `ROADMAP.md` Фаза 3, `REPORTS.md` v6.5.

## ⚠️ КРИТИЧНО: горячий провод GND

**Если при подаче питания провод GND начал греться — это признак короткого замыкания (КЗ) или неправильной проводки.**

### Немедленные действия

1. **Сразу отключите питание** (USB и/или внешний источник).
2. **Не включайте снова**, пока не найдёте причину.
3. Осмотрите провода и пайку на оплавление, потемнение, запах.

### Чеклист диагностики (мультиметр, режим прозвонки / сопротивление)

| № | Проверка | Ожидание | Если плохо |
|---|----------|----------|------------|
| 1 | **3.3 V ↔ GND** (без ESP32, только модуль TCA/EEPROM) | **разомкнуто** (∞ Ом) | КЗ на линии питания — ищите перепутанные VCC/GND, замыкание на корпус |
| 2 | **3.3 V ↔ SDA** | разомкнуто | SDA замкнут на питание |
| 3 | **3.3 V ↔ SCL** | разомкнуто | SCL замкнут на питание |
| 4 | **GND ↔ SDA** | разомкнуто | SDA на землю |
| 5 | **GND ↔ SCL** | разомкнуто | SCL на землю |
| 6 | **SDA ↔ SCL** | разомкнуто | линии I2C соединены между собой |
| 7 | Полярность **EEPROM DIP-8**: пин 8 = VCC, пин 4 = GND | по даташиту | чип вставлен наоборот → КЗ |
| 8 | **WP (пин 7)** EEPROM | на GND (для теста) | на VCC — только запрет записи, не КЗ |
| 9 | **A0–A2 (пины 1–3)** | на GND → адрес 0x50 | другие комбинации — другой адрес |
| 10 | **TCA A0, A1, A2** | все на GND → адрес **0x70** | иначе TCA не найдётся |
| 11 | Не перепутаны ли **SDA и SCL** между ESP32 и TCA | SDA→SDA, SCL→SCL | иногда «работает» через подтяжки, но даёт сбои |
| 12 | На **WROOM32** не используйте **GPIO 6–11** | flash SPI внутри модуля | КЗ/нестабильность |

> Подтяжки 4.7 кОм SDA/SCL → 3.3 V обязательны (на модуле TCA или отдельно).

## Порядок тестирования

1. **Этап 1:** ESP32-WROOM32 DevKit — отладка проводки и I2C.
2. **Этап 2:** после `>>> PASS <<<` на WROOM32 — перенос на **ESP32-S3** (целевая плата ПДА).

Один скетч `EEPROM_TCA_Test.ino` — пины выбираются автоматически по выбранной плате в Arduino IDE.

## Прошивка ESP32-WROOM32 DevKit

### Arduino IDE

| Параметр | Значение |
|----------|----------|
| Board | **ESP32 Dev Module** |
| Upload Speed | 921600 (или 115200 при ошибках) |
| CPU Frequency | 240 MHz |
| Flash Size | по вашему модулю (часто 4 MB) |
| Port | COM-порт DevKit |
| Monitor | **115200** бод |

### Шаги

1. Установить пакет **esp32** (Espressif Systems) в Board Manager.
2. Открыть `test_firmware/EEPROM_TCA_Test/EEPROM_TCA_Test.ino`.
3. Выбрать **ESP32 Dev Module**.
4. Подключить USB, выбрать COM-порт.
5. Upload → открыть Serial Monitor 115200.
6. При старте автоматически запустится `TEST`; ожидайте `>>> PASS <<<`.

### Команды Serial

- `TEST` — полный тест CH1 + CH2
- `SCAN` — скан I2C на главной шине и всех каналах TCA
- `CH0` … `CH7` — скан выбранного канала
- `HELP` — справка

## Распиновка TCA / EEPROM (одинакова для обеих плат)

### ESP32 → TCA9548A

| Сигнал | ESP32-WROOM32 | ESP32-S3 |
|--------|:-------------:|:--------:|
| 3.3 V | 3V3 | 3V3 |
| GND | GND | GND |
| SDA | **GPIO 21** | **GPIO 9** |
| SCL | **GPIO 22** | **GPIO 8** |

### TCA9548A

| Сигнал | Подключение |
|--------|-------------|
| VCC | 3.3 V |
| GND | GND |
| SDA / SCL | к ESP32 (см. таблицу выше) |
| A0, A1, A2 | **GND** → I2C-адрес **0x70** |

### EEPROM на каналах TCA

> Полная карта слотов ПДА: `proshivki/common/mux_channels.h`. Стенд проверяет **CH1** (универсальный) и **CH2** (броня).

| Канал | Слот ПДА | Линии TCA |
|-------|----------|-----------|
| CH1 | Универсальный / кабель кассы | SD1 / SC1 |
| CH2 | Броня | SD2 / SC2 |
| CH4–CH6 | Артефакты 1–3 | SD4–SD6 / SC4–SC6 |
| CH0, CH3 | Резерв | — |

Регион **TXN @ `0x80`** (кабельные терминалы) описан в `eeprom_protocol.h` / `eeprom_txn.h` — не затрагивается тестом @ `0x0100`. Сквозной тест терминала: `test_firmware/Terminal_Test/README_Terminal_Test.md`.

| EEPROM пин | Сигнал |
|------------|--------|
| 8 | 3.3 V |
| 4 | GND |
| 5 | SDA (SDn) |
| 6 | SCL (SCn) |
| 7 (WP) | GND |
| 1–3 (A0–A2) | GND → адрес **0x50** |

## Перенос на ESP32-S3

Когда на WROOM32 тест прошёл успешно:

1. Отключить питание.
2. Перепаять/переключить провода I2C:
   - SDA: GPIO **21** → GPIO **9**
   - SCL: GPIO **22** → GPIO **8**
3. В Arduino IDE: Board → **ESP32S3 Dev Module**, **USB CDC On Boot = Enabled**.
4. Загрузить тот же скетч, Serial Monitor 115200.
5. Снова `TEST` → `>>> PASS <<<`.

Логика TCA @ 0x70 и EEPROM @ 0x50 на CH1/CH2 не меняется.
