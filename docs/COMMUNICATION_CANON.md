## 2. Каналы связи (не путать)

| Канал | Назначение | Не используется для |
|-------|------------|---------------------|
| **UWB (BU03)** | Точная дистанция (м): зона аномалии, вход в ЗЗ, режим «один игрок», калибровка `AT+SETDEV` | Касса, банк, квесты |
| **LoRa (Ra-01)** | **Мастер-Пульт:** выброс, KILL/REVIVE/WIPE, радио-треки; ретрансляция Master→ПДА→ESP-NOW; опц. якоря полигона (да/нет) | Терминалы, переводы, покупки |
| **ESP-NOW** | Игровые пакеты на короткой дистанции: урон, ACK, beacon зоны, детектор аномалий | Терминалы, точные метры |
| **RSSI** | Грубое «сигнал есть / устройство рядом» (детектор, LoRa-якоря) | **Позиционирование, калибровка метров** |
| **EEPROM (TCA9548A)** | Чипы снаряжения; **терминалы** на **CH0** | — |

> **Устарело и удалено из планов:** LoRa-запросы ПДА↔банкомат/касса/квесты; протокол `EXT_REQ`; калибровка RSSI 5/10/20 м для дистанции.

## 3. Терминалы (банк, касса, квесты, мастерская)

**Модель:** терминал и ПДА **не общаются по радио**. Данные — через **общий EEPROM** на канале **CH0** (`mux_channels.h`).

### Два режима CH0

| Режим | Как работает | Адрес EEPROM |
|-------|--------------|--------------|
| **Handoff** | Терминал/программатор пишет чип → игрок **вставляет картридж** в CH0 → ПДА читает `applyChip()` | Заголовок чипа @ **`0x00`** |
| **Кабель** | **Настольная кассета** у терминала + **4-провод** (SDA, SCL, 3V3, GND) к **J_TRS / CH0** ПДА; игрок подключает ПДА кабелем | TXN-блок @ **`0x80`** (`eeprom_txn.h`) |

**Поток TXN (кабель):** терминал пишет PENDING → ПДА опрашивает ~200 мс → PROCESSING → SUCCESS/FAILED → терминал показывает UI → RESET.

**op_type:** `PURCHASE`, `BANK`, `QUEST`, `ADMIT`, `ATM` — см. `eeprom_protocol.h`.

**Прошивка кассы:** `proshivki/Cashier/Cashier_ESP32.ino` · тест: `test_firmware/Cashier_Test/`

## 4. Слоты TCA9548A (финал, актуализировано 09.09.2026)

| CH | Назначение | Разъём |
|:---:|---|:---:|
| **0** | Универсальный (переходники/расходники) + кабель терминалов | TRRS + **J_TRS** |
| 1, 4 | Резерв (нет на PCB) | — |
| **2, 3, 5, 6** | **Универсальные слоты** — любое снаряжение (броня, артефакты, устройства) — тип не закреплён за каналом, определяется полем `type` в самом чипе | TRRS |
| 7 | Запасной | — |

Эталон кода: `proshivki/common/mux_channels.h`.  
Старая схема CH1=универсальный/CH2=броня/CH4–6=арты была актуальна с 12.06.2026 по 09.09.2026. До этого — CH0=броня, CH1–3=арты, CH4=универсальный (до 12.06.2026).

## 6. UWB vs RSSI

| Задача | Технология |
|--------|------------|
| Вход в радиус аномалии | **UWB** |
| Вход в зелёную зону | **UWB** + ESP-NOW beacon |
| Калибровка на полигоне | **`AT+SETDEV`** (BU03) |
| «Аномалия где-то рядом» (ур. 25+, детектор) | **ESP-NOW** пакет + мигание LED |
| Грубая слышимость / якоря | **RSSI** (без метров) |

## 7. Физические ключи (не GPIO)

| Ключ | Цепь |
|------|------|
| **PWR** | Разрыв Li-Po → DC-DC |
| **SND** | Разрыв 5V → DFPlayer |
| **VIB** | Разрыв 5V → вибромотор |
| **BL** | Тумблер на корпусе: **ON→G37**, **AUTO→G38** (INPUT_PULLUP); **не** в цепи LED TFT (LED J_TFT → 3V3 постоянно) |

G37/G38/G47/G48 — входы положения тумблеров (**заняты**). Прошивка **не отключает** подсветку TFT программно (LED → 3V3 на v3).
