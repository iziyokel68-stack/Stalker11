# STALKER — приложение мастера

Единая программа на ноутбуке мастера: регистрация, список участников,
программатор устройств, общие оповещения, доска заданий, статистика, карта.

Канон: `docs/PROGRESSION.txt` §10–§11, `ROADMAP.md` Фаза 4.

## Запуск

```bash
cd stalker_app
pip install -r requirements.txt
python main.py
```

Базы событий: `stalker_app/events/stalker_event_<id>.db` (можно копировать на USB).
Скриншот карты копируется в `events/map_<event_id>/`.

## Каналы до ПДА игрока

USB Serial — **одно** устройство на ПК мастера (CHIP_BOX, полевое на столе, позже Мастер-Пульт / телефон). ПДА игрока по кабелю не подключают.

| Канал | Что передаёт |
|-------|----------------|
| **LoRa по №** | выброс, радио (трек), громкость, текст, ADMIT/REVIVE/KILL. `0` = все |
| **EEPROM-чип** | имя при регистрации (`type=3 sub=7`, имя @0x26), допуск, воскрешение, позже снимок статистики |

Имя не влезает в LoRa-пакет 8 байт — только на чип.

## Модули

| Меню | Что делает |
|------|------------|
| Событие | Игровой день, счётчики, экспорт/импорт `.db` |
| Участники | Список, № регистрации, прошивка чипа регистрации/допуска, LoRa-допуск |
| Программатор | **В этом окне:** чипы, аномалии, убежища, пресет ПДА на столе, роль терминала |
| Оповещения | Журнал; выброс **в минутах**; радио = трек; громкость DFPlayer 0–30 |
| Задания | Каталог квестов события (доска) |
| Статистика | Снимок вручную; полевой съём — чип «Сохранение» |
| Команды | LoRa на № или EEPROM-чип (не USB к ПДА) |
| Карта | Скриншот-подложка и маяки (UWB, убежище, аномалия, КПП) |

Громкость одна на DFPlayer: радио и уведомления. Клавиша SND на ПДА — вкл/выкл питания звука, не уровень.
