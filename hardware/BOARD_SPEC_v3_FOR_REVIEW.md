## 1. Что это

Игровой ПДА: ESP32-S3 + TFT ILI9341 320×240 + LoRa + UWB (BU03) + 5 слотов EEPROM (4× TRRS + шлейф **J_TRS** на **CH0**). Две платы-сэндвич:

| Плата     | Размер    | Контур   | Файл                          |
| --------- | --------- | -------- | ----------------------------- |
| **LOGIC** | 140×78 mm | полигон с вырезами (TFT, BU03) | `STALKER_PDA_LOGIC.kicad_pcb` |
| **POWER** | 140×78 mm | прямоугольник | `STALKER_PDA_POWER.kicad_pcb` |

Связь: **J_INTER 1×15** (2.54 mm). На LOGIC — вырезы под BU03.

> ⚠️ Если в KiCad стоит footprint 2×10 — заменить на **1×15** перед заказом PCB.

## 2. Питание

> **Текущая сборка:** ключа **SND нет**. DFPlayer питается от 5V вместе с ПДА (не через тумблер). Громкость — страница НАСТРОЙКИ на экране. G47/G48 не используются.

```
Li-Po → PWR (механический разрыв) → TPS63020 (5V)  → DFPlayer (всегда с ПДА)
                                                   → [VIB] → вибро LRA
            → TPS63020 (3.3V) → ESP, TFT VCC, LoRa, TCA, TRRS, BU03
                              → LED подсветки TFT (J_TFT LED → 3V3, постоянно)
```

> **PWR / VIB** — физические ключи в разрыве питания (**не GPIO**), если установлены. **SND нет.**  
> **BL** — тумблер на корпусе: **ON→G37**, **AUTO→G38**, GND; **не** в цепи LED.  
> **GPIO 47/48** не используются.

> Зарядный модуль — вне текущего scope документации.

## 3. Блоки — принцип работы

| Блок              | Принцип                                     | Пины ESP32                 |
| ----------------- | ------------------------------------------- | -------------------------- |
| **ESP32-S3**      | Управление, UI, протокол                    | —                          |
| **TFT M024-240320** | SPI, стекло 320×240. `tft_panel.h`: rotation 1 + MADCTL **0x88** (без MV) | G10–G14, RST G12; LED J_TFT → **3V3** (не GPIO) |
| **TCA9548A**      | 5 независимых I2C-каналов для EEPROM @ 0x50 | SCL **G8**, SDA **G9**     |
| **TRRS ×4 + J_TRS** | Съёмные картриджи 24LC256                 | CH0 (универсал + кабель), CH2/3/5/6 снаряжение |
| **LoRa Ra-01**    | Дальняя связь, SPI                          | G39–G41, SPI G13/14/40     |
| **BU03-Kit**      | UWB, дистанция по UART AT                    | Serial1 G1/G2, питание G42 |
| **DFPlayer**      | Звук с microSD                              | Serial2 G17/G18; 5 V вместе с ПДА (**SND нет**) |
| **Вибро LRA**     | 5 V через **физический ключ VIB**, ключ NPN | G21 (импульсы при поданном питании) |
| **Тумблеры**      | BL; G47/G48 не используются                 | G37/G38 (BL). Громкость — НАСТРОЙКИ на экране |

**Слоты чипов:** все EEPROM имеют адрес `0x50` → перед чтением `tcaSelect(channel)`. Эталон каналов — `proshivki/common/mux_channels.h`:

| CH | Назначение | Разъём |
|:---:|---|:---:|
| **0** | Универсальный + кабель кассы/терминалов (TXN @ `0x80`) | TRRS + **J_TRS** |
| 1, 4 | Резерв (нет на PCB) | — |
| **2, 3, 5, 6** | Универсальные слоты снаряжения (броня / артефакт по `type` чипа) | TRRS |

Распиновка TRRS (своя, не аудио CTIA/OMTP):

| Tip | Ring1 | Ring2 | Sleeve |
| --- | ----- | ----- | ------ |
| SDA | SCL   | 3.3 V | GND    |

**BU03 питание:** G42 → 220 Ω → 2N2222 → P-MOS (AO3401) → VCC модуля. Ключ на POWER, управление с LOGIC. Прошивка: `BU03_PINS_PLATE 1`, `BU03_PWR` OFF вне зоны UWB.

## 5. Логика работы — кто за что отвечает

Центр системы — **ESP32-S3**. Он опрашивает входы, решает игровую логику и отдаёт команды периферии.

**DFPlayer** — UART G17/G18; питание 5 V вместе с ПДА (**ключа SND нет**). Громкость — страница НАСТРОЙКИ.  
**Кнопки** — INPUT_PULLUP: **G4=DN**, **G5=RT**, **G6=OK**, **G7=ESC**.  
**Светодиоды** — G15 (220 Ω), G16 (100 Ω).  
**TCA9548A** — мультиплексор I2C для слотов EEPROM @ 0x50.  
**Экран** — M024-240320, стекло 320×240; после `begin()` — `tftApplyPanel()` (MADCTL **0x88**, без MV). LED J_TFT → **3V3**.  
**Физические ключи** — **PWR** (разрыв АКБ); **SND нет**; **VIB** если установлен; **BL** (G37/G38). G47/G48 не используются.  
**Тумблер BL** — положение **ON/AUTO** на **G37/G38** (INPUT_PULLUP); **не** разрывает LED.  
**LoRa** — дальняя связь 433 MHz, SPI.
**UWB (BU03)** — UART AT на **G1/G2**; питание G42 / P-MOS.  
**Вибромотор** — G21 → 2N2222; 5 V на POWER **после** физического ключа VIB.  
**Слоты** — TRRS-картриджи + J_TRS на CH0 (кабель терминала); запись — программатором/терминалом, чтение — ПДА через TCA. Handoff @ `0x00`, кабельные терминалы — TXN @ `0x80` (`eeprom_txn.h`).
