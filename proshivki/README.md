# Прошивки устройств STALKER

Один раз на базе заливаете `.ino` через Arduino IDE.  
Дальше устройство только подключаете USB к программе мастера — роль, лимиты, задания, аномалия, убежище, чип.

Не пересобирайте скетч, чтобы поменять кассу на банкомат или список квестов.

## Что заливать (боевые скетчи)

| Железка | Скетч | Плата в IDE | После заливки — USB в программаторе |
| --- | --- | --- | --- |
| **ПДА игрока** | `Pda/V1/PDA_ESP32/PDA_ESP32.ino` | ESP32-S3 Dev Module (N16R8) | Стенд: функции/пресет. В поле — чип или LoRa, не кабель к каждому |
| **Терминал** (касса, банкомат, доска, допуск, банк) | `Terminal/Terminal_ESP32/Terminal_ESP32.ino` | ESP32 Dev Module или ESP32-C3 | Вкладка «Терминал»: роль, лимиты RUB, задания QUEST |
| **Аномалия / убежище** | `Anomaly_GZ/Field_ESP32.ino` | ESP32-S3 (пины как у ПДА) | Вкладки «Аномалия» / «Убежище» |
| **CHIP_BOX** (программатор чипов) | `Cip_Programmer/Chip_Programmer_ESP32.ino` | ESP32-C3 SuperMini | Вкладка «Чип» |

Папка `Cashier/` — старое имя кассы. Актуальна только прошивка **Terminal**.

Тестовые стенды (`test_firmware/`) на полигон не ставить.

## Терминал: роль и лимиты

Один корпус. В программе мастера:

1. Подключить USB, дождаться `STALKER:TERMINAL`.
2. Вкладка **Терминал** → роль `STORE` / `ATM` / `QUEST` / `ADMIT` / `BANK`.
3. Лимиты (0 = без потолка):
   - касса — максимальная покупка за одну операцию;
   - банкомат — максимальное снятие и максимальный вклад.
4. Если роль **QUEST** — можно сразу записать задания с доски события.
5. **Записать в устройство**.

Память переживает выключение. Список заданий лежит на кассете EEPROM; лимиты и роль — во флеш ESP (NVS).

## Поле и чипы

Тот же принцип: `.ino` один раз, потом `CONFIG_WRITE` с вкладки Аномалия / Убежище / Чип.
