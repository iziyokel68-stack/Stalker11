# STALKER — приложение мастера

Единая программа на ноутбуке мастера: регистрация, список участников,
программатор устройств, общие оповещения, доска заданий, статистика, карта.

Канон: `docs/PROGRESSION.txt` §10–§11, `ROADMAP.md` Фаза 4. Заливка устройств: `proshivki/FLASHING.md`.

## Запуск

```bash
cd stalker_app
pip install -r requirements.txt
python main.py
```

Базы событий: `stalker_app/events/stalker_event_<id>.db` (можно копировать на USB).
Скриншот карты копируется в `events/map_<event_id>/`.

## Каналы до ПДА игрока

USB Serial — **один стационарный ESP** на ноутбуке мастера: **CHIP_BOX**.
Это и программатор чипов, и стол регистрации / снятия данных, и пульт LoRa
(`LORA_TX`). Программа на ПК — `stalker_app`. Касса/банкомат в поле — отдельные терминалы, не этот кабель.

| Канал | Что передаёт |
|-------|----------------|
| **LoRa по ID игрока** | выброс, радио (трек), текст, ADMIT/REVIVE/KILL. `0` = все. Имена не в эфире |
| **Мост EEPROM** | регистрация: CHIP_BOX пишет чип + TXN, ПДА на шнуре забирает ID и UID |
| **EEPROM-чип** | допуск, воскрешение, позже снимок статистики |

UID ПДА выдаёт мастер при добавлении игрока, не считывается с железа.
Громкость — страница **НАСТРОЙКИ** на ПДА (ВНИЗ тише, ОК громче). Ключа SND нет:
DFPlayer питается вместе с ПДА, 0 = без звука.

## Модули

| Меню | Что делает |
|------|------------|
| Событие | Игровой день, счётчики, экспорт/импорт `.db` |
| Участники | Список, ID = LoRa, UID при добавлении, мост регистрации, LoRa-допуск |
| Программатор | **В этом окне:** чипы, аномалии, убежища, пресет ПДА; терминал — роль, лимиты, задания. `.ino` один раз, дальше USB |
| Оповещения | Журнал; выброс **в минутах**; радио = трек; цель = ID |
| Задания | Каталог квестов события (доска) |
| Статистика | Снимок вручную; полевой съём — чип «Сохранение» |
| Команды | LoRa на ID (в т.ч. воскрешение и KILL) или EEPROM-чип |
| Карта | Скриншот + маяки. Вставьте железку шнуром — номер появится сам; клик ставит её на карту |

Ключа SND на ПДА нет. Громкость 0–30 в настройках на экране.
